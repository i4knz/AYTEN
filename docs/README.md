## الوثائق القادمة (بحسب الترتيب المطلوب في البرومبت الرئيسي، القسم 29)

1. دراسة الجدوى الأولية — تتطلب بحثاً موثقاً بالمصادر.
2. تحليل المنافسين (Shopify, Salla, Zid, WooCommerce, ExpandCart) — بأسعار وروابط وتاريخ تحقق.
3. تعريف العملاء المستهدفين + دليل مقابلات التحقق.
4. عرض القيمة وصيغ اختباره.
5. وثيقة PRD الكاملة للإصدار الأول.
6. بقية الوثائق (UX، التصميم، API، الأمن، الاختبار، النشر، التشغيل، التسعير، الاستقطاب، خطة 90 يوماً).

## ملاحظة عن محتوى المستودع الحالي

- `index.html` و`images/` هما صفحة هبوط مبنية (Build) لنشاط استشارات إعلانات Google وMerchant Center تحت اسم Ayten.
  الملف ناتج بناء (React مضغوط في ملف واحد) وليس كوداً مصدرياً. **لم يُعدَّل**.
- كود المنصة سيُبنى في مجلد مستقل بعد الاعتماد، حتى لا يتأثر الموقع الحالي.
